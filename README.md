🎲 Random Generator API Project

This is my first API-based project built while learning the fundamentals of APIs and asynchronous requests.
The goal of this project is to practice fetching data from APIs and displaying it dynamically on a webpage.

🔗 Live Demo:
https://get-random-by-aryan.netlify.app/

🚀 Features

Generates random data using APIs
Simple and clean user interface
Demonstrates API fetching using JavaScript
Fully deployed using Netlify

🧠 What I Learned

Through this project, I practiced:
How APIs work
Making HTTP requests
Using JavaScript fetch()
Handling API responses
Updating the DOM dynamically
Deploying a project using Netlify

🛠️ Tech Stack

HTML
CSS
JavaScript
Public APIs
Netlify (Deployment)

⚙️ How It Works

User clicks the Generate button
JavaScript sends a request to an API
The API returns random data
The webpage updates dynamically
